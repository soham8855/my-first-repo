
# Technologies Used

BlockVote is built with modern web technologies to ensure performance, security, and maintainability:

- **Vite**: Fast, modern frontend build tool
- **TypeScript**: Typed JavaScript for better code quality and developer experience
- **React**: Component-based UI framework
- **shadcn-ui**: High-quality UI components
- **Tailwind CSS**: Utility-first CSS framework
- **Supabase**: Backend-as-a-service for authentication and database
- **Web3.js and Ethers.js**: Libraries for blockchain interaction
- **Truffle and Ganache**: Smart contract development and testing framework
